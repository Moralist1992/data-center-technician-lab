# Data Center Technician Lab

Self-directed learning lab for preparing for Data Center / IT Technician work.

> This repository documents learning and lab practice. It does not claim professional production data-center experience.

## Course blocks

1. Server Anatomy
2. BMC
3. Server Boot
4. Hardware Diagnostics
5. Data Center
6. Linux for Technicians
7. Ticket Workflow
8. Technical Interview

## Diagnostic mindset

**symptoms → evidence → hypothesis → test → action → verification → escalation/documentation**
