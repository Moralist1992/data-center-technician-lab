# Block 08 — Technical Interview Preparation

## Purpose
Translate the technical material into interview-ready answers for an entry-level Data Center Technician role.

## What a first technical interview is likely checking
- basic server hardware;
- BMC and out-of-band management;
- boot concepts;
- basic Linux awareness;
- safe troubleshooting logic;
- runbooks;
- escalation;
- clear communication.

## Universal troubleshooting answer
> First, I would understand the symptom and collect evidence. Then I would check the BMC, logs, or console and follow the runbook. I would take the approved action, verify the result, and document or escalate the issue if necessary.

## Avoid
Do not say `I would replace the GPU` simply because it is not detected. Say what you would check first.
