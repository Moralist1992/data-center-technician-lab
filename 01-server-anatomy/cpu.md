# CPU

## What is a CPU?

**CPU = Central Processing Unit**

The CPU executes instructions and performs calculations required by the operating system, applications and services.

It is one of the main compute components of the server.

## Basic role

```text
Application
    ↓
Operating System
    ↓
   CPU
    ↓
Calculations / instructions
```

The CPU works together with:

- RAM
- motherboard
- storage
- PCIe devices
- operating system

## CPU in a server

Servers may have:

- one CPU
- multiple CPU sockets

Multi-socket systems require appropriate memory architecture and system design.

Multiple CPUs do not automatically mean CPUs are hot-swappable.

## Interview wording

Do not describe the CPU as the component that "controls everything".

Better:

> The CPU executes instructions and performs the main computational work of the system.

## Troubleshooting

A CPU-related problem may appear as:

- system instability
- boot failure
- CPU not detected
- abnormal temperature
- hardware errors
- performance problems

Possible causes can include:

- CPU failure
- socket/contact problem
- motherboard issue
- cooling problem
- firmware/BIOS issue
- power problem

## Interview question

### "What does the CPU do?"

Good answer:

> The CPU is the main processing unit of the server. It executes instructions and performs the calculations required by the operating system and applications.
