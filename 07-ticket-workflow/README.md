# Block 07 — Ticket Workflow and Operations

## Standard workflow
```text
Alert/Ticket → Understand symptom → Collect evidence → Check runbook
→ Diagnose/isolate → Approved action → Verification → Documentation → Close/Escalate
```

## Runbook
An approved internal procedure for a particular operational problem. It can include checks, expected results, safe actions, replacement steps, verification and escalation.

## Good ticket information
Record what happened, what was checked, what was found, what changed, and whether the result was verified.

## Escalate when
- the procedure requires it;
- the problem is outside your access/responsibility;
- the action is unsafe;
- required troubleshooting did not solve it;
- a higher-level engineer is needed.

## L1 principle
Do not hide uncertainty. A precise escalation is better than a guess.
